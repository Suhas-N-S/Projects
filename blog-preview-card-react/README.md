# Blog Preview Card

This project is a solution to the **Blog Preview Card** challenge, implemented using **React** and **Tailwind CSS**.

## 📌 Overview  
A simple and responsive blog preview card that displays an article title, publication date, description, and an image. The card also includes a category tag and hover effects for interactivity.

## 🛠️ Technologies Used  
- **React**: For building the UI components  
- **Tailwind CSS**: For styling and responsiveness  

## 🚀 Features  
- Responsive and centered design  
- Hover effect on the blog title  
- Tailwind CSS utility classes for styling  
- Clean and modular component structure
